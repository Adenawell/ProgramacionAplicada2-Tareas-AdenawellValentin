¿Qué es una API REST?

Una API es básicamente aquel puente o via que permite que dos aplicaciones diferentes se comuniquen y compartan información entre sí. Luego REST es simplemente un estilo o forma de diseñar esa comunicación.Entonces cuando los juntamos las dos cosas nos queda  una API REST que es una conexión que usa las reglas del protocolo HTTP  para que los sistemas web se entiendan de manera sencilla.

¿Qué la diferencia de una página web normal?

La diferencia principal está en quién es el que va a leer la informació porque Una página web normal devuelve archivos con diseño ya sea HTML o  CSS para que un humano los vea bonitos en el navegador y por otra API REST no tiene diseño esto devuelve solo los datos puros porque está hecha para que otra aplicación o programa los lea y trabaje con ellos.


¿Por qué devuelve JSON?

Devuelve los datos en formato JSON porque es súper ligero, fácil de leer y, sobre todo, universal.
