 ¿Qué es Express.js?
 
 Express.js es un framework muy ligero para Node.js. que es una herramienta que nos da una estructura para crear aplicaciones web y APIs de forma mucho más rápida y organizada.

¿Qué problema resuelve sobre Node puro?

El principal problema que resuelve esque si nosotros queremos levantar un servidor web usando solamente Node.js puro, nos tocaria escribir un montón de código manual y repetitivo hasta para tareas muy sencillas como por ejemplo separar la URL. Express.js resuelve esto porque ya trae funciones hechas que manejan toda esa parte compleja por detrás, ahorrándonos a nosotros mucho tiempo y haciendo que nuestro código quede mucho más limpio y fácil de leer.

¿Qué es una ruta en Express?

Una ruta es la instrucción que le damos al servidor para decirle qué tiene que hacer cuando alguien entra a una URL específica usando un método HTTP en especifico.
